# Code With AI Interactive Quiz Application

An interactive web-based technical assessment application developed by **Aryan Raj** (JECRC University) for Lecture 10.

## Overview
The application tests core software engineering concepts including LLM token prediction, Git commit formatting conventions, Test-Driven Development (TDD) lifecycle, separation of concerns (CSS), and algorithmic time complexity.

## Features
* Clean, responsive card interface featuring a custom navy and gold college theme.
* Instant visual feedback on answer selection (Green for correct, Red for incorrect).
* Dynamic progress indicator and real-time score calculation.
* Post-quiz performance summary with retry capability.
* Accessible keyboard navigation and mobile-first layout.

## Technologies Used
* HTML5 (Semantic Structure)
* CSS3 (Custom Variables, Flexbox, Animations)
* JavaScript (DOM Manipulation, State Management)

## How to Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/Aaryan-Raj21/interactive-quiz-app.git
   ```
2. Open `index.html` in any modern web browser.
